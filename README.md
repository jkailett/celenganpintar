## Struktur

```
├── index.html                # Landing page (long-form sales page)
├── 404.html                  # Halaman error
├── CNAME                     # Custom domain
├── css/
│   └── style.css             # Stylesheet utama
├── js/

│   ├── index.html            # Daftar artikel
│   └── posts/                # Artikel blog
├── financial-planning/

├── proposal/
```
